# Eval results — cadenceux-skill-creator 2.4.2 — 2026-11-18

Only the release-archive steps changed, so one targeted case was run on Haiku against both 2.4.2
and the released 2.4.1, each answer drawn only from its own skill folder.

Prompt: "I've tagged and pushed v1.3.0 of a CadenceUX skill. Give me the exact steps and
commands to build its release .zip and .skill archives and attach them to the GitHub release.
Which files end up in the archive, and which are left out and why?"

| Check | 2.4.2 | 2.4.1 |
|---|---|---|
| Builds from the tag, not a working folder | ✅ `build_release.sh` (git archive) | ✅ fresh clone |
| Same builder as `cadenceux-github` | ✅ | ❌ own `zip -r` recipe |
| Leaves out `.claude-plugin/`, with the reason | ✅ | ✅ |
| Leaves out `evals/` and `maintainer/` (export-ignore) | ✅ | ⚠️ `maintainer/` only; `evals/` shipped |
| Validates with `--archive`, attaches four files incl. unversioned copies | ✅ | ✅ |

2.4.2 gives the shared builder and the same archive contents `cadenceux-github` describes;
2.4.1 gives the older recipe, which is why the two skills' archives differed.
